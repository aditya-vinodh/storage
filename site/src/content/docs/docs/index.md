title: Introduction
description: Files for agents and people, with versioning, sharing and cleanup built in.
---

Agents and people save, find and share files in one place. Agents use it over
MCP or the command line, with the same commands and the same output either
way. Every change is kept as a version, nothing is shared until you share it,
and rules clean up what you no longer need.

It's open source and runs as a single container on your own servers.

## What you can do

- **Store files from any agent.** Screenshots of a pull request, research
  notes, generated reports, test results, recordings or logs.
- **Get files back without filling an agent's context.** A read returns a
  local path or a short-lived link. Content comes back inline only when an
  agent asks for it.
- **Share safely.** Give a teammate, a Google Workspace domain, a GitHub org
  or team, or a service access to a collection, or hand out a read-only link
  that expires.
- **Clean up on a schedule.** Delete after a number of days, after a pull
  request merges, or keep only the last few versions. Deleted files can be
  restored for a grace period.
