How it works

Agents make things. People need to see them.

Agents produce screenshots, reports, notes and data all day. Files live in collections, each with its own access and cleanup rules, and agents and people work in the same ones.

Store

Agents and people put files into collections through MCP or the CLI. Every write is a new version, so nothing gets overwritten by accident.

“Save this week's competitor research to my notes.”

Share

Give access to a teammate, your Google Workspace domain, a GitHub org or team, or another agent. Or send a link that expires.

“Share the Q3 report with finance for a week.”

Clean up

Rules like “delete after 30 days” or “delete 7 days after the pull request merges” tidy up for you, with a grace period to restore.

“Keep only the last 3 versions of each report.”
Principles

Safe to hand to an agent. Simple enough to just use.

Built for agents acting on your behalf, so access is narrow, nothing is lost, and every change is on the record.

Secure by default

  • Private until you shareNothing is public. You decide who sees what, down to a single collection.
  • Narrow keys for agentsGive an agent a token that can only write to the collections it needs, or sign it in with OAuth.
  • Links that expireShare a read-only link that stops working when you say.
  • An audit logEvery write, share, link use and delete is recorded.

Easy for agents and people

  • Versioning built inEvery write is a new version. Bring back any earlier one in a single command.
  • One sign-in, every agentSign in once with Google. Any MCP client can then use your files.
  • Same tools everywhereThe command line and MCP have the same commands, arguments and output.
  • Yours to runOpen source, and runs as a single container on your own servers.

Get started

Three commands to your first file.

Install the CLI, sign in to your server, and hand your agent the tools.

1

Install the CLI

$npm install -g @storage/cli

The npm package isn't published yet. Until it is, build from source with the first-run guide.

2

Sign in

$storage login --server https://storage.your-company.com

Opens your browser to sign in with Google. Running your own server? It's one container with docker compose.

3

Connect your agent

$claude mcp add storage -- storage mcp

Any MCP client works. Point it at the command storage mcp, or at your server's hosted endpoint, /mcp.

Then ask your agent: “Save a summary of today's meeting and share it with the team.” Working on code? “Store a screenshot of the new checkout page on my pull request.”

Works with

Bring the agents you already use.

Anything that speaks MCP can use it. Agents with a shell can also use the command line.
